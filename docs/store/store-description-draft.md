## 3. 詳細な説明 (Google Play: 4000 字以内、推奨 1000-2000 字)

```text
家族の習い事スケジュールをシンプルに管理する無料アプリです。

夫婦や祖父母で「今日は誰の何の習い事？」「持ち物は？」「送り迎えはどっち？」と毎週繰り返す会話を、アプリ 1 つに集約しました。1 度入力すれば家族全員で共有でき、前日と当日に自動で通知が届きます。

■ こんな方におすすめ
・複数の子どもがいて、習い事スケジュールが複雑になっている家庭
・夫婦で送り迎えを分担している家庭
・祖父母や別居の家族にも予定を共有したい
・紙のカレンダーや LINE のメモでは抜け漏れが多くて困っている

■ 主な機能

【月カレンダー表示】
1 か月の習い事予定がひと目で分かるカレンダー。色分けで子どもごと・習い事ごとに識別できます。

【家族で共有】
招待コード 1 つで配偶者・祖父母・別居の家族と世帯共有。複数の端末で同じ予定を確認・追加・編集できます。

【前日と当日の通知】
標準で「前日 21 時」「当日開始 30 分前」に通知。時間帯と頻度はお好みで変更可能です。

【持ち物リスト】
習い事ごとに必要な持ち物を登録。通知に持ち物リストを含められるので、忘れ物が減ります。チェックを付けることで「準備済み」を家族で共有できます。

【子どもごとの管理】
複数の子どもの予定をまとめて管理。子どもごとに表示色を設定でき、見落としを防ぎます。

【シンプルな操作】
スマホ操作に慣れていない方でも迷わない設計。最小限の入力でスケジュール追加できます。

■ プライバシーへの配慮
・お子様の個人情報は世帯内（家族）のみで共有され、外部に提供されません。
・位置情報・連絡先・カメラへのアクセスは取得しません。
・広告は Google AdMob のバナー広告を画面下部に表示します。広告同意はアプリ起動時または設定画面から変更でき、「広告を非表示」を選択することもできます。
・「子供向け扱い」を有効化し、個人化広告を無効化しています。
・詳しくはプライバシーポリシーをご確認ください: TBD（公開 URL は申請時に確定）

■ 動作環境
・Android 8.0 (Oreo) 以上
・通知機能の利用には、通知の許可が必要です

■ 料金
・基本機能はすべて無料です
・運営のため、画面下部にバナー広告を表示します
・有料プラン・課金アイテムはありません（v1.0 時点）

■ お問い合わせ
support@miraikousou.com （TBD: 社長確定後反映）

■ 開発元
個人開発、宮内・上野（みらいこうそう）
```

**字数カウント**: 約 870 字 (本文のみ、推奨 1000-2000 字レンジに収まる)
**追加予定**: Sprint 3 着手前に designer-N のスクリーンショット文言と整合させて 1200 字程度に調整

## 5. プライバシーラベル (Google Play Data Safety section、別途構造化入力)

| 項目 | 回答案 | 備考 |
|---|---|---|
| 収集データ | メールアドレス、ユーザー入力データ（子どもの情報、スケジュール）、広告 ID | プライバシーポリシー §2 と整合 |

| データ暗号化 | あり（通信時 HTTPS、保存時 Supabase 暗号化） | |

| 子供向けアプリ | はい（保護者管理型） | TFCD ON、Family-friendly content rating |
